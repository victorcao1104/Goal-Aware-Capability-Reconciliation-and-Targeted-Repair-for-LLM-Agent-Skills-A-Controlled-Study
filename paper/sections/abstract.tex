\begin{abstract}
Agent Skills can request plausible actions that exceed the current user's authority. This study evaluates a pipeline that independently extracts task permissions and Skill behavior, identifies potential unauthorized effect paths, and selects runtime restrictions that preserve permitted data and fields. All model roles use GPT-6 Luna. We separate original-bundle static analysis, controlled execution, and transferred attack text, and distinguish live model plans from deterministic stress replay. Across 1,920 scheduled executions, the unmediated live executor shows no observed attacks in the main attacked cohort and completes 99.3\% of tasks. Under stress replay, goal-targeted repair reduces observed attack success from 100\% to zero and achieves 83.3\% joint security and task success, compared with 33.3\% for a provenance-aware deny-only gateway. However, an equally selective task-only repair gateway matches these outcomes. The results support provenance-sensitive repair within this closed setting but do not establish incremental benefit from goal-graph selection. Shared workflow templates, synthetic fixtures, one model, and the absence of independent human annotation limit generalization. The artifact preserves frozen inputs, traces, failures, and independent deterministic acceptance checks.
\end{abstract}
