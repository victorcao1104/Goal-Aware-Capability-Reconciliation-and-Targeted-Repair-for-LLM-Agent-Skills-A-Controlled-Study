# v4 实验结论：独立授权与行为审查

本轮已完成 48 个样本、两次重复、五种方法，共 480 条方法轨迹。模型均为 gpt-6-luna。**结果没有证明“样本骗过联合权限生成器，但被独立授权＋图审查拦下”这一预期，也没有证明显式图具有稳定额外价值。**

## 与你的设想对应的结果

权限生成器看 Skill 的 Mixed 组，以及只看可信任务的 Isolated 组，在各自 24 次攻击条件使用中，错误放大权限均为 0。原始规则和结构校验后的规则都如此。因此，不能把这些样本称为成功欺骗权限生成器的案例，也不能用这轮数据证明隔离带来了实测提升。

独立扫描器的 14 次实际请求均完整提取了声明的动作，没有被“隐藏诊断上传”等文本诱导漏报。这些响应在不同任务与方法之间复用；不能把 96 次逻辑使用说成 96 次独立扫描成功。

| 方法 | 有合格证据的正确审查 | 原始判断与参考一致 | 正常任务必要效果完成 |
| --- | ---: | ---: | ---: |
| 联合权限＋无图 | 62/96 | 87/96 | 38/48 |
| 联合权限＋有图 | 54/96 | 85/96 | 34/48 |
| 独立权限＋无图 | 60/96 | 84/96 | 34/48 |
| 独立权限＋有图 | 53/96 | 88/96 | 37/48 |
| 独立权限＋运行时来源追踪 | 不适用 | 不适用 | 44/48 |

“有合格证据的正确审查”要求：三分类判断正确、模型调用流程成功、审查证据没有校验错误。即使程序因证据错误回退为“无法确认”，恰好与参考答案相同，也不计入这个主要指标。“原始判断与参考一致”只是读取未经修改的模型 decision 字段所得的次级诊断，不检查证据是否合格。

有图相对无图的预注册主要指标，在联合权限下下降 8.33 个百分点，在独立权限下降 7.29 个百分点。但是，不能直接据此说“图让模型更不会判断风险”：很多模型输出把完整句子、动作范围填进本应为单一动作 ID 的字段，导致证据引用或路径终点校验失败。

例如，模型正确判断需要阻止上传，路径也正确，却将动作字段写成“s8 sends data…”而不是单独的“s8”。程序按冻结规则将其转为无法确认。字段采用自由字符串、提示词未逐字段明确编码要求，是这版实现的局限。原始判断指标的方向并不一致：有图相对无图在联合权限条件下下降 2.08 个百分点，在独立权限条件下上升 4.17 个百分点。不能单独强调后一项为正面结果。因此更准确的解释是：**这套实现没有显示稳定图收益，且主要指标明显受到证据接口错误影响。** 本轮没有事后放宽校验、修正模型答案或重跑来改善分数。

## 真正观察到的缺口

**独立授权仍可能错误理解可信任务。** 运行时基线的四次正常任务失败来自两份不同的合同响应：模型一边允许提交，一边又引用“未列出的操作禁止”生成覆盖整个发送操作的禁止规则，最终把合法提交也挡住。引用是真实的，但规则语义是错的。三个失败还复用了同一份响应，并非三个独立模型错误。

这印证了一个边界：隔离能切断 Skill 对授权输入的直接影响，但不能保证授权模型理解正确。本轮实测的是过度限制，而非你原先担心的恶意扩权。

五种方法都没有产生未经授权的模拟效果，但原因包括权限合同、运行时检查、事前阻断和分支未执行，不能全部归功于图。独立权限＋有图组曾错误允许一个潜在危险的条件分支样本；该实例没有触发分支，所以没有发生危险效果。这说明“没发生危险操作”和“审查判断正确”必须分开统计。

## 费用、完整性与范围

实际记录 426 次模型请求：112 次权限生成、14 次扫描、300 次审查。新增费用保守估算 **0.177864500 美元**，原研究累计 **1.435230375／20 美元**。

运行发生一次记录完整性中断：95 组与 425 份响应已保存，下一项审查没有响应或预算预留记录。原程序未保留内部异常，无法确诊根因。使用原冻结程序恢复后仅新增一次请求，原有 520 个文件的哈希均未改变。没有挑选性重跑或删除失败样本。最终全部模型响应正常，预算没有悬而未决的预留。

离线重放核对了 527 个证据文件、全部 480 条轨迹和汇总字段。费用必须按完整 v4 开始余额计算，不能只计算中断恢复后的差额。

这些是六类相关、人工编写但未经独立人工标注的声明式流程。实例主要改变任务编号，部分条件分支改变运行状态；不是 48 个独立真实 Skill。无图和有图共享来源追踪与证据校验，比较的是“把显式图索引提供给模型”的收益，而不是整个系统是否使用图算法。全部效果均为模拟，不代表真实文件或网络攻击的成功率。

你的架构动机仍然合理，但目前应把论文贡献谨慎定位为可复现的信任边界与失败模式分析，而不能写成已验证的图安全优势。下一轮若要改进，首先应解决证据字段接口和合同语义冲突，再用独立收集、更有差异的行为样本检验；这些都需要新的实验冻结，不能修改本轮结果。
