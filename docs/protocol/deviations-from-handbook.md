# Implemented scope versus the initial handbook

The handbook is the design starting point, not a claim that every proposed extension was completed. This table must accompany interpretation of the final paper.

| Initial proposal | Implemented study | Consequence |
|---|---|---|
| Model/provider choice and multiple model roles | User explicitly selected gpt-6-luna for all experimental roles | No cross-model generalization |
| Independent human contracts and path labels | User explicitly requested fully automatic benchmark-label/deterministic evaluation | No human agreement or human-grounded path F1 |
| Task/attack-template groups isolated across splits | Named families isolated; broad workflow templates recur | Not a strict unseen-template test; code/fixture precision is optimistic for this small grammar |
| Official SkillInject Docker execution | Passive complete-bundle acquisition, static original-bundle analysis, and independent closed-tool container | No native benchmark reproduction or directly comparable official ASR |
| Cross-language/cross-layer program analysis | LLM source-anchored graph plus closed Python-tool AST recognition | Unsupported semantics remain unproved; not a sound whole-program analyzer |
| General Task-to-Capability authority validation | Verbatim task evidence, explicit bound identities, deterministic scope checks | Validator does not prove semantic entailment; compiler remains a trust dependency |
| General least-cost repair, possible source rewriting | Enumerated sink restrictions, handle/field filtering, coarse resource selection | Minimum only in the enumerated set; no native script patching or global minimality |
| Full model-driven dynamic tool loop | At most two JSON plan rounds, 16 actions each | Finite plan-and-feedback scaffold; no unlimited agent autonomy |
| Method comparisons B0–B5 | B0/B1/B2/B3/B4/B5 plus stronger B2P/B2R task-only baselines | Separates provenance and repair gains from incremental graph contribution |
| End-to-end model attacks and ablations | Live paired model plans, separately labelled fixed-script stress | Replay ASR is not a measured LLM susceptibility rate |
| Broad semantic component ground truth | Finite permission atoms and closed-tool observed node/data dependencies | No general semantic path-coverage or real-program accuracy claim |
| Rich domain tasks | Document/Code/Email framing over the same structured record substrate | Scenario categories are not native application integrations |

The template-sharing limitation and cohort distinctions were recorded in frozen-design-notes.md before formal inference. The experiment's purpose is to establish a reproducible controlled comparison and identify failure modes; it cannot support the broader empirical claims that the unimplemented parts of the handbook would require. The final manuscript explicitly describes these limits and preserves negative results.
